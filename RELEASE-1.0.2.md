# pnAutoMine 1.0.2

Добавлена статистика добычи для PlaceholderAPI и TAB scoreboard.

Изменения:

- placeholders шахты, которая сбросится следующей: `%pnautomine_next_mine_*%`;
- placeholders следующего типа шахты: `next_type` и `next_type_display`;
- персональный подсчёт добытых игроком блоков за текущий цикл шахты;
- подсчёт по настраиваемым группам материалов и конкретным Bukkit Material;
- рассчитываемая зарплата по `value-per-block`;
- готовый пример `tab-mining-scoreboard-example.yml` в стиле списка добытых ресурсов;
- автоматический сброс статистики вместе со сбросом шахты;
- тесты учёта и очистки статистики.

Для статистики в sidebar требуются PlaceholderAPI и TAB. Основная работа шахт
по-прежнему требует WorldEdit.
