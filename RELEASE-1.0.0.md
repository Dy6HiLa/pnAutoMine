# pnAutoMine 1.0.0

`pnAutoMine` - плагин для автоматических шахт.

Что есть в версии 1.0.0:

- создание шахт по выделению WorldEdit
- автоматический сброс шахт по таймеру
- несколько типов шахт с разным составом блоков
- автоматическая смена типа шахты по порядку
- голограмма над шахтой с названием, типом, блоками и временем до сброса
- команды для создания, просмотра, сброса и настройки шахт

Если на сервере установлены FancyHolograms или DecentHolograms, плагин покажет голограммы над шахтами.
