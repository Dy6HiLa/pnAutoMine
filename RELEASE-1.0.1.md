# pnAutoMine 1.0.1

Исправляющий релиз pnAutoMine.

Изменения:

- исправлен сбой запуска `bStats Metrics class has not been relocated correctly`;
- метрики и проверка обновлений переведены на актуальный pnLibrary runtime;
- добавлены PlaceholderAPI placeholders текущей шахты игрока;
- добавлена поддержка настраиваемого sidebar scoreboard через TAB;
- добавлен готовый пример `tab-scoreboard-example.yml`;
- сохранены placeholders конкретных шахт `%pnautomine_<mine_id>_<value>%`.

Требования:

- Paper и Java 17 или новее;
- WorldEdit;
- PlaceholderAPI и TAB нужны для sidebar scoreboard.
